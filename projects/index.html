Approach

  1. End to end. I take a feature from system design to backend, frontend and the production release.
  2. Modular by default. Services that deploy on their own, so each client gets only the modules they need.
  3. Automate the dull parts. If people do it by hand every day, an LLM or a script should probably do it.
  4. Ship, then sharpen. I code, break things, fix them, and ship them.
